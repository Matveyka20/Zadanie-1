# RequestSystem

## Назначение проекта

Система предназначена для автоматизации работы с заявками: их создания, отслеживания статусов и распределения между исполнителями. Проект разработан в рамках лабораторной работы №1 по анализу предметной области и составлению требований к программной системе.

## Краткое описание функций

- **Создание заявки**: пользователь (заявитель) может сформировать новую заявку с указанием типа, описания и срочности.
- **Назначение исполнителя**: администратор или координатор может назначить заявку конкретному сотруднику.
- **Изменение статуса**: исполнители и администраторы могут обновлять статус заявки (например, «Новая», «В работе», «На проверке», «Завершена»).
- **Просмотр списка заявок**: все участники системы могут просматривать список заявок с фильтрацией по статусу, типу и исполнителю.
- **История изменений**: для каждой заявки сохраняется хронология действий (кто и когда изменил статус или добавил комментарий).

## Структура проекта

Проект организован в соответствии с требованиями лабораторной работы:

- `Фамилия_Имя_Группа_RequestSystem/` — корневая папка проекта.
  - `docs/` — документация (модели предметной области, требования, диаграммы).
  - `src/` — исходный код системы.
  - `tests/` — тесты для проверки функциональности.
